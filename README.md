# Predicting-Insurance-Claim-Amounts-
Predicting Insurance Claim Amounts

Project Overview:
This project predicts medical insurance claim amounts using a regression approach. The goal is to analyze personal data, visualize key feature relationships, and build a model to estimate insurance charges.

Objective:
Estimate the medical insurance claim amount based on personal data. 

Dataset:
Name: Medical Cost Personal Dataset
Source: Kaggle
Type: Tabular (CSV)

Technologies & Libraries:
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn

Project Workflow:
1️⃣ Data Cleaning & Preprocessing
2️⃣ Exploratory Data Analysis (EDA) & Feature Visualization
3️⃣ Linear Regression Model Training
4️⃣ Model Evaluation (MAE, RMSE)

Skills Demonstrated:
Regression modeling
Feature correlation analysis and visualization
Model performance evaluation using MAE and RMSE

How to Run the Project:

# Clone the repository
git clone (https://github.com/Basma-Yasmine/Predicting-Insurance-Claim-Amounts-/tree/main)

# Install dependencies
pip install pandas numpy matplotlib seaborn scikit-learn

# Open and run the Jupyter Notebook
jupyter notebook
